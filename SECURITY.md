# Security policy

Nox FZE welcomes reports of security vulnerabilities in its websites, software
and infrastructure.

**Report privately** to contact@noxfze.com with "Security" in the subject, a
description of the issue and the steps to reproduce it. Please do not open
public issues for vulnerabilities.

We acknowledge reports promptly, keep you informed while we investigate, and
ask for coordinated disclosure: please allow us reasonable time to resolve an
issue before publishing details.

Machine-readable contact details: https://noxfze.com/.well-known/security.txt
